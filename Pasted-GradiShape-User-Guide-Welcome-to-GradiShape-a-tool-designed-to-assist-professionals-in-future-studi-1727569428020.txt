Introduction
GradiShape is an innovative application that helps you analyze and understand different types of change by using gradient sliders representing various characteristics. It provides visualizations and AI-generated analyses to deepen your insights into the changes you're studying.

Getting Started
Entering the Title of Change
Open the Application: Launch GradiShape on your device.
Locate the Text Box: At the top of the application, find the "Title of Change" text box.
Input the Title: Type in the title of the change you wish to examine.

Using the Change Gradients
Understanding Gradient Sliders
Change Gradients Window: Scroll down to find the Change Gradients window.
Gradient Sliders: There are nine sets of gradient sliders, each representing a spectrum between two opposing characteristics (gradient labels) of change.
Total Gradient Labels: In total, there are 18 gradient labels (two per slider).
Viewing Gradient Definitions
View Definitions: Click on "View Definitions" at the top of the Change Gradients window to see specific definitions for each gradient label.
Setting Gradient Values
Adjust Sliders: Move the slider towards the gradient label that best represents the characteristic of the change you're examining.
Value Range: Each gradient label can have a value between 0 and 100.
Spectrum Balance: If you assign 60% to one gradient label, the opposing label automatically receives 40%. You're indicating the relative significance between two opposing characteristics.
Understand the Spectrum: Remember, you're not assigning independent values to each label; you're choosing the significance of one gradient label versus its opposite on the spectrum.

Processing Gradients
Adjusting and Resetting Sliders
Process Gradients: Once you've adjusted all the sliders, click the "Process Gradients" button to generate the analysis.
Reset Sliders: If you need to make changes, click the "Reset Sliders" button to readjust the sliders.

Interpreting the Results
Change Pattern Visualization
Radar Chart Display: After processing, a radar chart appears in the Change Pattern Visualization window.
Pattern Representation: The chart displays a unique pattern based on the gradient values you've set.
Labels and Positions: The labels around the radar chart correspond to the gradient labels, represented by natural abbreviations (e.g., ST for Stable).
Position Numbers: Each label has a position number (e.g., P3 for the third position), indicating its placement on the chart in a clockwise direction.
Usage: These positions help you refer to specific parts of the pattern for further research.
Gradient Values Window
Gradient Listings: Next to the radar chart, the Gradient Values window lists each gradient along with the values you've assigned.
Exporting Data: At the bottom of this window, you can export the values to a CSV or JSON file for further analysis.

AI Analysis
Generating AI Baseline Analysis
AI Analysis Button: After processing the gradients, click the "AI Analysis" button located next to the “Process Gradients” button.
AI Analysis Window: An AI-generated baseline analysis appears at the bottom of the application.
Contextual Understanding: The AI considers the title of change you've entered and understands the gradient definitions to generate its analysis.
Summary and Insights: The AI provides a summary to help you gain more insights and understand how your gradient values compare.
Comparing User and AI Values
Line Chart Visualization: At the bottom of the AI's output, a line chart displays a visual comparison between your gradient values and the AI's baseline values.
Note on Variability: Since the AI analysis is in an experimental phase, results may vary.

Additional Features
Light and Dark Mode
Toggle Display: Switch between light and dark modes based on your visual preference.
AI Model Capabilities
Temporal Context Understanding: The AI model is proficient at understanding whether the change you're examining is set in the past, present, or is a future ideation.

Notes and Considerations
Experimental Phase: Keep in mind that the AI analysis feature is experimental.
Spectrum Balance Reminder: Increasing the value of one gradient label decreases the value of its opposing label.
Further Research: Use the export feature to save your gradient values for additional analysis.
Understanding Context: The AI's ability to grasp temporal context enhances the relevance of its analysis.

Thank you for choosing GradiShape to explore and understand the complexities of change. We hope this guide enhances your experience with the application.
