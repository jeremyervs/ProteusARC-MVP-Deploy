Overview
We are introducing new features to enhance the application's ability to analyze changes based on additional user-provided context. These features include an "Advanced" options section with additional input fields and settings that influence the AI model's analysis and summary generation.

User Interface Updates
Advanced Options Dropdown

Placement: Directly beneath the existing Title of Change text box.
Element: An "Advanced" label accompanied by a dropdown arrow (▼).
Behavior: Clicking the dropdown arrow expands or collapses the advanced options section.
Advanced Options Contents

Upon expansion, the advanced options section reveals the following elements:

a. Description Text Box

Label: Description
Type: Multi-line text area (larger than the Title of Change text box).
Purpose: Allows users to provide additional details and nuances for the AI model to consider.
Optional: Users may leave this field empty if they choose.
b. Knowledge Section

Label: Knowledge
Options: Two mutually exclusive choices (use radio buttons to enforce single selection).
Internal
Definition: Indicates that the change is unique to the user's context and not publicly known.
AI Behavior: The AI model should primarily rely on the Title of Change and Description provided by the user. It may use general world knowledge to better understand the unique information.
Public
Definition: Indicates that the change is generally known in the public sphere (e.g., the Civil Rights Movement).
AI Behavior: The AI model should primarily rely on accurate, publicly available information about the change.
Selection Constraint: Only one option can be selected at any time.
c. Timeline Section

Label: Timeline
Options: Three mutually exclusive choices (use radio buttons).
Past
Definition: The change occurred in the past.
Present
Definition: The change is currently happening.
Future
Definition: The change is a projected or imagined future scenario.
AI Behavior: The selected timeline should influence the AI model's analysis and summary.
Selection Constraint: Only one option can be selected at any time.
Functional Requirements
Title of Change Text Box

Status: This field is now required.
Validation: Implement form validation to ensure the user cannot proceed without entering a title.
Advanced Options Behavior

Default State: The advanced options section is collapsed upon initial view.
Expansion: Clicking the dropdown arrow expands the section to display additional fields.
Optional Fields: All fields within the advanced options are optional; users may choose to fill in any, all, or none.
Input Controls

Mutual Exclusivity: Use radio buttons for the Knowledge and Timeline sections to enforce single-option selection within each.
Default Selections: No default option is pre-selected in the Knowledge and Timeline sections.
AI Model Integration

Context Utilization:
If provided, the Description adds depth to the AI's context understanding.
The Knowledge selection guides the AI on how much to rely on user-provided information versus public knowledge.
The Timeline selection informs the AI about the temporal context, affecting its analysis.
Fallback Behavior: If advanced options are not used, the AI model continues to rely solely on the Title of Change.
User Experience Enhancements

Tooltips/Help Icons: Include informational tooltips or help icons next to the Knowledge and Timeline labels explaining their purposes.
Error Messages: Provide clear error messages if the required Title of Change field is left empty upon submission.
Accessibility: Ensure all new elements are accessible and comply with standard accessibility guidelines.
Summary of Changes
Required Field: Title of Change text box is now mandatory.
Advanced Options: Introduced an expandable section containing:
An optional Description text box for additional context.
A Knowledge section with Internal and Public options to indicate the nature of the change.
A Timeline section with Past, Present, and Future options to specify the temporal context.
AI Model Adjustments: Modify the AI model to incorporate new inputs when available, adjusting its analysis and summary generation accordingly.
Validation and Constraints: Implement input validation and enforce mutual exclusivity where necessary.
